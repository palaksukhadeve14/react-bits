# ⚛️ React Bits

**Small projects. Practical learning. One step closer to mastering React.**

React Bits is my personal collection of beginner-friendly React projects, built to learn by doing. Each project helps me understand React fundamentals, practice JavaScript, and gradually develop my frontend development skills through hands-on implementation.

---

## 📌 Projects

### 🎨 01. BG Changer

A simple interactive application that allows users to change the background color with a click.

- **Focus:** React state management and event handling
- **Tech:** React, JavaScript, CSS
- **Project folder:** [`Bgchanger`](./Bgchanger)

### 🔐 02. Password Generator

A customizable password generator that creates random passwords based on the selected length and character options.

- **Focus:** React Hooks, state updates, references, and JavaScript logic
- **Tech:** React, JavaScript, CSS
- **Project folder:** [`PasswordGenerator`](./PasswordGenerator)

## 🚀 Run a Project Locally

**1. Clone the repository**

```bash
git clone https://github.com/palaksukhadeve14/react-bits.git
cd react-bits
```

**2. Navigate to a project**

```bash
cd Bgchanger
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal. To run another project, navigate to its directory, then repeat the installation and startup steps.
